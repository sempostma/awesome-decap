# Contribution Guidelines

- Add one item per pull request and explain why it belongs on the list.
- Use the format `- [Name](link) - Description.` with a short description ending in a period.
- Put the item in the right section; add it at the bottom of that section.
- The project must work with Decap CMS, or be clearly useful to Decap users.
- Mark unmaintained or read-only repositories with `(archived)`.
- Check spelling and grammar, and make sure the link works.
